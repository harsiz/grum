it asks for administrator because it's both a log and mod bot and i'm lazy. no, it won't go rogue and delete your server.

commands

  1. /config log-channelrequired

    pick your private log channel. nothing gets displayed without this one

  2. /config test

    sends a test embed and warns you about missing permissions, like view audit log

  3. /config detection-rate

    controls how confident the ai has to be before it deletes. default is 60%, but with jev over-flagging images, try 85 to 90 so you get way fewer false positives

  4. /config automod

    has the auto-mod switches. things worth looking at:

    • images:False if the image flagging is still too annoying, text and word list stay on
    • strikes, window_minutes and timeout_minutes if you want to change the “2 strikes in an hour = 30 min timeout” rule
  5. /config ignore-channel

    for channels you don't want stored or logged, like mod-only channels. nsfw channels are already handled automatically

  6. /automod exempt-roleoptional

    for any role that shouldn't be auto-moderated. anyone with manage messages is already exempt

  7. /config panel

    to look over everything at the end and toggle individual events

/config routeoptional

only if you want voice logs in a separate channel from message logs, totally optional 🥺
